【描述】如果招标文件中要求的质保期低于法定/行业最低标准，或响应时间低于行业合理标准，就判定为违规。

【法规依据】
1. 《建设工程质量管理条例》第四十条：建设工程最低保修期限为：
   - 基础设施工程、地基基础工程和主体结构工程：设计文件规定的合理使用年限
   - 屋面防水工程、有防水要求的卫生间/房间和外墙面的防渗漏：5年
   - 供热与供冷系统：2个采暖期/供冷期
   - 电气管线、给排水管道、设备安装和装修工程：2年
2. 《建设工程质量保证金管理办法》（建质〔2017〕138号）第八条：缺陷责任期一般为1年，最长不超过2年，由发承包双方在合同中约定。

【质保期/缺陷责任期最低标准（按项目类型）】
1. 房屋建筑工程：缺陷责任期≥12个月
2. 市政基础设施工程：缺陷责任期≥12个月
3. 装修工程：缺陷责任期≥12个月
4. 设备采购安装：质保期≥12个月（行业惯例≥24个月）
5. 信息系统/软件开发：质保期≥12个月（行业惯例≥36个月）
6. 货物采购：质保期≥12个月（行业惯例≥18个月）

【响应时间合理标准（按服务类型）】
1. 日常运维服务：响应时间≤4小时（行业惯例）
2. 应急维修服务：响应时间≤2小时（行业惯例）
3. 软件系统故障：响应时间≤4小时（行业惯例）
4. 设备故障抢修：响应时间≤8小时（行业惯例）
注：响应时间标准为行业惯例上限参考值，低于上述标准不一定违规，但明显不合理（如要求1分钟内响应）应标记预警。

【公式】
IF 项目类型 IN ['房屋建筑工程','市政基础设施工程','装修工程','设备采购安装','信息系统/软件开发','货物采购'] AND 缺陷责任期/质保期 < 12个月 THEN 标记为违规
IF 项目类型 = '信息系统/软件开发' AND 质保期 < 36个月 THEN 标记为预警（建议≥36个月）
IF 响应时间 < 1小时 THEN 标记为预警（明显不合理）
注：质保期标准依据《建设工程质量管理条例》第四十条和《建设工程质量保证金管理办法》第八条

【开发说明】
1. 输入数据：合同条款中质保期/缺陷责任期字段、响应时间字段、项目类型字段
2. 检查逻辑：
   - 类型判断：识别项目类型
   - 阈值比较：根据项目类型匹配对应的最低标准进行比较
   - 预警分级：区分"违规"和"预警"两级
3. 输出：是否违规/预警（布尔值）、当前值、对应标准值、项目类型
