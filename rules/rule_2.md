【描述】如果招标文件的项目概况里出现了"适当"、"合理"、"视情况"、"酌情"等模糊词汇，或者与发改委立项批复的内容不一致，就判定为违规。

【法规依据】《招标投标法》第二十条：招标文件不得要求或者标明特定的生产供应者以及含有倾向或者排斥潜在投标人的其他内容。《招标投标法实施条例》第三十二条：招标人不得以不合理的条件限制、排斥潜在投标人。

【模糊词汇量化标准】
1. 明确禁止类模糊词汇（直接违规）：
   - "适当"、"合理"（无后续量化说明时）、"视情况"、"酌情"、"原则上"、"约"、"左右"、"大概"
2. 需结合上下文判断类词汇（需大模型辅助判定）：
   - "相关"、"必要"、"足够"、"充分"——需检查后文是否有量化补充
3. 判定规则：
   - 匹配到明确禁止类词汇 → 直接标记违规
   - 匹配到需判断类词汇 → 检查前后100字内是否有量化说明，无则标记违规

【公式】
IF 招标文件.项目概况内容 MATCH '适当|合理（无量化）|视情况|酌情|原则上|约|左右|大概' THEN 标记为违规
IF 招标文件.项目概况内容 MATCH '相关|必要|足够|充分' AND NOT EXISTS(前后100字内量化说明) THEN 标记为违规
IF 招标文件.项目概况 <> 立项批复.项目概况（语义相似度<0.8） THEN 标记为违规

【开发说明】
1. 输入数据：招标文件项目概况、立项批复文件项目概况
2. 检查逻辑：
   - 关键词匹配：正则匹配模糊表述关键词（分两级：明确禁止类 + 需判断类）
   - 上下文分析：对需判断类词汇，检查前后100字是否有量化补充
   - 文本比对：对比招标文件与立项批复的项目概况内容（语义相似度阈值0.8）
3. 输出：是否违规（布尔值）、匹配到的模糊词汇、差异内容、语义相似度数值
